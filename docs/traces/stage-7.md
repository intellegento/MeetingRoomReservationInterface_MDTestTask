### 1. Документация Next 16.4.0 и значение

- IP компьютера: `ipconfig getifaddr en0` → **`<LAN-IP>`** (`en1` пуст).

Без настройки разрешены только `localhost`, его поддомены и hostname, с которым сервер запущен. Сравнивается только hostname из `Origin` (у no-cors — из `Referer`), без схемы и порта.

### 2. Предложение (не внесено, ждёт одобрения)

IP в репозиторий не записывается: он меняется от сети к сети (DHCP) и привязан к машине. Хосты передаются переменной окружения при запуске.

`next.config.ts`:

```ts
import type { NextConfig } from "next";

// Дополнительные хосты для dev-сервера (телефон в локальной сети): ALLOWED_DEV_ORIGINS="<LAN-IP>".
// Next применяет allowedDevOrigins только в dev (router-server.js: блокировка под `development`), в production — нет.
const allowedDevOrigins = (process.env.ALLOWED_DEV_ORIGINS ?? "")
  .split(",")
  .map((host) => host.trim())
  .filter(Boolean);

const nextConfig: NextConfig = {
  reactStrictMode: true,
  ...(allowedDevOrigins.length > 0 && { allowedDevOrigins }),
};

export default nextConfig;
```

Запуск dev с доступом из сети:

```bash
ALLOWED_DEV_ORIGINS="$(ipconfig getifaddr en0)" npx next dev -H 0.0.0.0
```

На телефоне открыть `http://<LAN-IP>:3000`. `-H 0.0.0.0` пишется явно, хотя `next dev` и так слушает все интерфейсы (`*:3001` у вашего сервера). Production с доступом из сети: `npm run build && npx next start -H 0.0.0.0`.

Свойства:
- **Секретов нет.** В конфиге нет значений, только имя переменной. IP передаётся при запуске и в git не попадает.
- **Production не ослабляется.** `allowedDevOrigins` читается только dev-сервером. Без переменной поведение не меняется даже в dev: разрешены только `localhost` и hostname запуска.
- В переменной — точные хосты, без `*`. Шаблон вида `192.168.*.*` открыл бы dev-ресурсы всем устройствам сети.

Опционально, тоже на одобрение, — сверх задания:
- скрипт `"dev:lan": "next dev -H 0.0.0.0"` в `package.json`;
- строка `ALLOWED_DEV_ORIGINS=` в `.env.example` (только имя, policy-check требует пустых значений);
- абзац в README.

Тест не предлагаю: поведение dev-сервера Next — не код проекта. Проверка ручная, по шагам выше.
