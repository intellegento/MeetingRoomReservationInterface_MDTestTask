# Инциденты

Формат: дата, этап, что случилось, причина, что сделано, ссылки.

## INC-1 (R6). Время старта этапа 0 записано без секунд

- **Дата:** 2026-10-08. **Этап:** 0.
- **Что случилось:** в `docs/time-log.md` старт этапа 0 записан как `2026-10-08 19:33 (+06)`, хотя `date` вывел `Thu Oct  8 19:33:50 +06 2026`. Секунды отброшены — это округление, нарушение правила AGENTS.md «оценивать или округлять время нельзя, только date».
- **Причина:** формат записи времени не был зафиксирован; агент переформатировал вывод `date` вручную.
- **Что сделано:** при ревью этапа 0 старт восстановлен по исходному выводу `date` (`2026-10-08 19:33:50 +0600`); в AGENTS.md закреплён формат `date '+%Y-%m-%d %H:%M:%S %z'` и запись вывода целиком; в testing.md предложена проверка формата в `policy-check`.
- **Ссылки:** `docs/traces/stage-0.md` → «Ревью документов», R6; коммит `b0546fa`.

## INC-2. Работа после закрытия этапа 0 без записи времени

- **Дата:** 2026-10-08. **Этап:** вне этапов (после закрытия этапа 0, строка `0b` в time-log).
- **Что случилось:** исправления по ревью и deny-правила (`.claude/settings.json`, раздел в `docs/security.md`, коммит `7158d59 stage 0: deny rules`) сделаны без `date` на старте и в конце. Время старта и длительность не измерены. Агент заметил это только после коммита и предложил запись постфактум вместо того, чтобы начать работу с `date`.
- **Причина:** в AGENTS.md обязанность выполнять `date` описана только внутри «Порядка работы над этапом N» (шаги 2 и 8). Работа вне этапа (по отдельной команде после закрытия этапа) под этот порядок формально не попадала, а правило «Нельзя» запрещает только оценивать и округлять время, но не требует его записывать. Автоматической проверки, что у каждого коммита есть строка в time-log, нет.
- **Что сделано:** в time-log добавлена строка `0b` со стартом «не записан», концом по дате коммита `7158d59` (`2026-10-08 20:16:35 +0600`) и фактом «не измерен»; время не оценивалось и не восстанавливалось. Предложены правка AGENTS.md и проверка в `policy-check`; заказчик одобрил. В AGENTS.md добавлен раздел «Время — для любой работы»; создан `scripts/policy-check.mjs` (проверка time-log и истории коммитов) и хук `.githooks/pre-commit` (`git config core.hooksPath .githooks`). Работа записана строкой `0c`.
- **Ссылки:** `docs/time-log.md` (строка `0b`); коммит `7158d59`.
