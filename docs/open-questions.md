# Открытые вопросы

Здесь собраны места в [docs/tz.md](tz.md), которые можно понять по-разному. Колонка «Рекомендация» — предложение исполнителя. Решения заказчика — в разделе [«Решения»](#решения). Колонка «Статус» показывает, решён ли вопрос. Решения перенесены в [docs/requirements.md](requirements.md).

Пример «сейчас» везде: **2026-10-08 10:10 по Бишкеку (UTC+6)**, то есть `2026-10-08T04:10Z`.

## Решения

Решения заказчика от 2026-10-08, записаны без изменений.

```text
Q1. Пояс комнаты ROOM_TIMEZONE=Asia/Bishkek (UTC+6) и на клиенте, и на сервере.
    «Сейчас» вычисляется одной функцией. Часы сервера главные: его «сейчас» в поясе
    комнаты даёт окончательный вердикт. Клиент использует свои часы, переведённые в
    этот пояс, только для подсказок. Отказ сервера из-за расхождения часов UI
```
