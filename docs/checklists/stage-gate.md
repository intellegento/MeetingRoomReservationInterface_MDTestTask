# Чек-лист закрытия этапа

Проходится перед коммитом `stage N: <суть> (gate green)`. Результат копируется в `docs/traces/stage-N.md`: каждый пункт отмечен и подкреплён доказательством.

- [ ] **Команда на этап была.** Первая строка трейса — цитата команды заказчика на старт этапа.
- [ ] **Gate зелёный.** `npm run gate` завершился с кодом 0, вывод (или его итоговые строки) вставлен в трейс.
- [ ] **Красный прогон был.** В трейсе есть вывод прогона, где новые тесты падали до реализации, и падали по правильной причине.
- [ ] **Трейс заполнен с доказательствами:** план, ID требований этапа, изменённые файлы, вывод тестов, результаты ручных мутаций (если правило критичное, см. [testing.md](../testing.md)), отклонения от плана и их причины.
- [ ] **Время записано.** Старт и конец в `docs/time-log.md` взяты из вывода `date`, факт посчитан по ним, ничего не оценено и не округлено. Заполнена колонка «что пошло не так».
- [ ] **Требования сверены.** Для каждого ID этапа в [requirements.md](../requirements.md) есть тест с этим ID в названии, и критерий приёмки выполнен. Если что-то не сделано, это явно записано в трейс.
- [ ] **Нет нарушений [AGENTS.md](../../AGENTS.md):**
  - [ ] нет `.skip` / `.only` / `xit` / `it.todo`;
  - [ ] нет `@ts-ignore` / `any` без записанной причины; каждое `eslint-disable … -- <причина>` этапа перечислено в трейсе;
  - [ ] ни один тест не ослаблен и не удалён ради прохождения: число тестов не меньше, чем в прошлом трейсе; в `git diff` тестов нет удалённых `expect` и подменённых ожидаемых значений;
  - [ ] бизнес-правила только в `src/domain`, там нет `Date.now()` / `new Date()` без аргумента;
  - [ ] domain не мокается в тестах;
  - [ ] компоненты не импортируют `src/api`;
  - [ ] новые зависимости записаны в журнал [architecture.md](../architecture.md);
  - [ ] `.env*` (кроме `.env.example`) и `~/.ssh` не трогались.
- [ ] **Инциденты** этапа записаны в `docs/traces/incidents.md`, ссылки на них есть в трейсе.
- [ ] `docs/traces/INDEX.md` ссылается на трейс этапа.
- [ ] После коммита и push — **СТОП**, следующий этап только по команде.
