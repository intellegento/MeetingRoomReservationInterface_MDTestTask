# Чек-лист перед сдачей

## Код и тесты
- [ ] **У каждого ID есть код и тест.** Для каждого ID из [requirements.md](../requirements.md) с уровнем unit/api/ui найден тест с этим ID в названии (`grep -rn '"<ID>:'` по тестам). Для уровня manual есть отметка в разделе «Ручные сценарии» ниже. Таблица соответствия ID → тест вставлена в финальный трейс.
- [ ] **`npm run gate` зелёный** на чистом клоне (`npm ci && npm run gate`).
- [ ] **Поиск запрещённого ничего не находит** в `src/` и тестах:
  - [ ] `.skip(`, `.only(`, `xit(`, `it.todo(`;
  - [ ] `@ts-ignore`, `@ts-expect-error` без записанной причины;
  - [ ] `: any`, `as any`, `<any>` без записанной причины;
  - [ ] `Date.now(` и `new Date()` в `src/domain`;
  - [ ] импорт `src/api` или `@/api` в `src/components`.

## Ручные сценарии (локально и на демо)
- [ ] **Создание:** завтра `14:00–15:00` «Демо» → бронь в списке.
- [ ] **Правка:** `14:00–15:00` → `15:00–16:00` → список обновлён. Дату в форме изменить нельзя.
- [ ] **Удаление:** подтверждение → брони нет в списке.
- [ ] **409 через флаг:** dev-панель → «Симулировать конфликт» → сохранить → сообщение, список обновлён (видна чужая бронь), данные формы на месте, поля времени помечены, пометка снимается после правки.
- [ ] **Медленная сеть:** dev-панель → «Медленная сеть» → видно состояние «Сохраняем…», двойной клик не создаёт двух броней.
- [ ] **Прошлая дата:** только просмотр, создать/изменить/удалить нельзя, есть пояснение.
- [ ] **Сегодня с прошедшими слотами:** нельзя выбрать начало раньше текущей минуты по Бишкеку. Начавшиеся брони только для чтения и с пояснением.
- [ ] **Состояния:** загрузка, пустая дата, ошибка загрузки с «Повторить».
- [ ] **Клавиатура:** весь сценарий без мыши, фокус виден.
- [ ] **320 px:** нет горизонтальной прокрутки, все действия доступны. Также проверены 1280 px.
- [ ] **Телефон, dev по сетевому адресу:** `ALLOWED_DEV_ORIGINS="$(ipconfig getifaddr en0)" npm run dev:lan`, на телефоне в той же сети `http://<IP>:3000` — список загружается, кнопки работают, создание и удаление проходят (INC-9).
