# Требования

Источник истины: [docs/tz.md](tz.md). Разбор ТЗ: [docs/traces/stage-0.md](traces/stage-0.md). Решения по спорным местам: [docs/open-questions.md → «Решения»](open-questions.md#решения).

- **[ТЗ]**: требование прямо есть в тексте ТЗ.
- **[РЕШЕНИЕ Qn]**: этого нет в ТЗ, но заказчик решил в [open-questions.md](open-questions.md#решения) (2026-10-08).
- **[ДОПУЩЕНИЕ]**: этого нет ни в ТЗ, ни в решениях заказчика. Это наше инженерное решение, оно ждёт подтверждения.
- **✎**: строка изменена по решениям от 2026-10-08. **🆕**: новая строка. Полный список — в разделе [«Журнал изменений»](#журнал-изменений).

Уровни проверки:
- **unit**: тест чистых функций, например валидации.
- **api**: тест mock-сервера (route handlers) через HTTP-контракт.
- **ui**: тест компонентов (Testing Library).
- **manual**: ручная проверка в браузере.

## Общие условия для примеров

- Пояс комнаты `ROOM_TIMEZONE=Asia/Bishkek` (UTC+6) на клиенте и на сервере — см. B9 [РЕШЕНИЕ Q1].
- Если не указано иное, «сейчас» = **2026-10-08 (чт) 10:10:00** по Бишкеку. Сегодня `2026-10-08`, вчера `2026-10-07`, завтра `2026-10-09`, суббота `2026-10-10`.
- Время в примерах — `HH:mm` по Бишкеку. Если дата не указана, берётся **завтра** (`2026-10-09`), чтобы правило B6 не мешало проверкам.
- Коды ответов [РЕШЕНИЕ Q11]:
  - **`400`** — битый запрос: неверный формат, неизвестные поля;
  - **`422`** — нарушение бизнес-правила;
  - **`409`** — только пересечение с другой бронью.
- Формат тела ошибки [РЕШЕНИЕ Q11]: `{ error: { code, message, field?, details?, conflictWith? } }`.
- Код ошибки `DURATION_STEP` задан решением Q2. Коды `DATE_IN_PAST` (B6: прошедшая дата, `field: "date"`) и `START_IN_PAST` (B6/B12: сегодня, старт раньше текущей минуты, `field: "start"`) заданы решением Q19. Имена остальных кодов (`OUTSIDE_WORKING_HOURS`, `START_NOT_BEFORE_END`, `DURATION_TOO_SHORT`, `DURATION_TOO_LONG`, `BOOKING_LOCKED`, `TITLE_TOO_LONG`, `OVERLAP`, `NOT_FOUND`, `INVALID_REQUEST`) — [ДОПУЩЕНИЕ].
- **Порядок проверок на сервере** [ДОПУЩЕНИЕ]: 404 (бронь не найдена) → 400 (формат) → 422 в порядке B11 → B1 → B2 → B3 → B4 → B10 → B6 (`DATE_IN_PAST`) → B6/B12 (`START_IN_PAST`) → `title` → 409 (B5). Возвращается первая найденная ошибка. Клиент проверяет в том же порядке через те же функции `src/domain`.
- «Отклонено» значит, что сервер отвечает `422` с кодом ошибки, а UI показывает ошибку у поля и не отправляет запрос.
- Язык интерфейса — русский [РЕШЕНИЕ Q17].
